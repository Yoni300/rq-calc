# RQ Calc

Калькулятор характеристик персонажа для Royal Quest Online: клас, рівень, очки характеристик, спорядження з заточкою, печатками й картами, таланти, аура, бафи, еліксири, витратні та колекція. Рахує атаку, DPS, здоров'я, захист, EHP, шанс крита, опір стихіям і расам тощо.

## Встановлення

Завантаж **RQ-Calc-Setup.exe** з [останнього релізу](https://github.com/Yoni300/rq-calc/releases/latest) і запусти. Програма оновлюється сама: нові версії завантажуються у фоні, а встановлюються після перезапуску.

Windows може показати «Windows захистила ваш ПК» (програма не підписана) → «Докладніше» → «Виконати в будь-якому разі».

## Розробка

- Запуск з коду: `start.cmd`
- Локальна збірка інсталятора: `npm run dist` → `dist/`
- **Випуск оновлення:** підняти `version` у `package.json`, закомітити й виконати `npm run release` — інсталятор і `latest.yml` викладаються в GitHub Releases, і всі встановлені копії оновляться самі.

## Звідки дані й формули

База предметів, карт, печаток, талантів і формули — з «RQ Calc» від Anon (версія «65+LestaChanges», [тема на форумі](https://royalquest.net/index.php?topic=408.0)). Логіку розрахунку перенесено з його C#-коду на JavaScript (`src/engine.js`), тому результати мають збігатися з оригінальним калькулятором.

Оновити дані з нової версії бази:

```
node tools/export-data.mjs шлях\до\rqdata.sqlite
```

Печатки в базі Анона застаріли, тому вони беруться з [Royal Quest Wiki](https://royalquest.info) (категорія «Магические печати»). Оновити печатки з вікі:

```
npm run update-stamps
```

## Публічні білди

Вкладка «Білди» показує збірки інших гравців. Сервер — безкоштовний Supabase, інструкція підключення: [server/README-uk.md](server/README-uk.md).

## Структура

- `src/engine.js` — рушій розрахунку (працює і в Node, і в браузері)
- `app/` — інтерфейс
- `data/` — вивантажена база (`rqdata.js`) та іконки
- `tools/export-data.mjs` — вивантаження з `rqdata.sqlite`
- `tools/update-stamps-wiki.mjs` — актуальні печатки з вікі (кеш у `source/wiki-stamps.json`)
- `test/smoke.js` — швидка перевірка рушія; `test/compare.js` — звірка з оригінальними бібліотеками RQ Calc
