# RQ Calc

Калькулятор характеристик персонажа для **Royal Quest Online**.

Собери персонажа как в игре: класс, уровень, характеристики, экипировка с заточкой, печатями и картами, таланты, гильдийские таланты, ауры (свои и группы), баффы, эликсиры, расходники и коллекция. Калькулятор посчитает атаку, урон в секунду, здоровье, защиту, EHP, шанс крита, сопротивления стихиям и расам и многое другое.

## Возможности

- **Окно персонажа как в игре** — слоты экипировки на своих местах, модель персонажа или костюм на фоне игровых локаций.
- **Экипировка** — заточка, печати (актуальные, с Royal Quest Wiki) и карты с описанием бонусов; подсказка к предмету в игровом стиле.
- **Таланты** — ветки талантов класса и гильдийские таланты.
- **Эффекты** — своя аура и ауры союзников по группе, баффы, эликсиры, расходники.
- **Ивенты** — бонусы предметов, которые работают только во время ивента.
- **Сравнение** — можно зафиксировать результат и видеть разницу после каждого изменения.
- **Билды** — сохранение своих билдов, код билда для обмена и вкладка «Сборки игроков» с публичными билдами, лайками и фильтром по классу.
- **Три языка** — русский, украинский, английский.
- **Автообновление** — новые версии скачиваются в фоне и ставятся после перезапуска.

## Установка

1. Скачай **RQ-Calc-Setup-x.x.x.exe** из [последнего релиза](https://github.com/Yoni300/rq-calc/releases/latest).
2. Запусти — программа установится и откроется.

Windows может показать «Windows защитила ваш компьютер» (программа не подписана) → «Подробнее» → «Выполнить в любом случае».

## Откуда данные и формулы

База предметов, карт, талантов и формулы расчёта взяты из «RQ Calc» от Anon (версия «65+LestaChanges», [тема на форуме](https://royalquest.net/index.php?topic=408.0)). Логика расчёта перенесена с его C#-кода на JavaScript (`src/engine.js`), поэтому результаты совпадают с оригинальным калькулятором.

Печати в старой базе устарели, поэтому они берутся с [Royal Quest Wiki](https://royalquest.info) (категория «Магические печати»).

## Для разработчиков

- **Тестовая версия:** `start.cmd` (или `npm start`) запускает программу прямо из исходников, с пометкой «ТЕСТ» и отдельным профилем (`%APPDATA%q-calc-test`, при первом запуске копируются билды из основной программы). Окно само перезагружается при изменении файлов в `app/`, `src/`, `data/`.
- **Опубликовать обновление:** `publish.cmd` — спросит «что нового», поднимет версию, закоммитит и выложит релиз; игроки получат обновление за несколько минут.
- Сборка установщика: `npm run dist` → папка `dist/`
- **Выпуск обновления:** поднять `version` в `package.json`, закоммитить и выполнить `npm run release` — установщик и `latest.yml` выкладываются в GitHub Releases, и все установленные копии обновятся сами.
- Обновить данные из новой базы RQ Calc: `node tools/export-data.mjs путь\к\rqdata.sqlite`
- Обновить печати с вики: `npm run update-stamps`
- Сервер публичных билдов — бесплатный Supabase, инструкция: [server/README-uk.md](server/README-uk.md)

### Структура

- `src/engine.js` — движок расчёта (работает и в Node, и в браузере)
- `app/` — интерфейс
- `data/` — выгруженная база (`rqdata.js`) и иконки
- `tools/` — выгрузка базы, печати с вики, правки данных, выпуск релиза
- `test/smoke.js` — быстрая проверка движка
